# 我的日程

个人日程管理 App：课表、日程、待办、倒计日和今日总览合在一处，数据全部存在设备本地，断网可用；Android 端把提醒注册成系统级本地通知，App 未打开甚至被划掉时到点仍会提醒。

实现是原生 JavaScript（ES Modules）单页应用，没有框架、没有构建步骤、没有后端依赖。

## 功能

- **首页总览**：今日课程、最近日程、待办与倒计日一屏汇总，假期/节日有单独提示；今日日程、待办、倒计时使用独立白色卡片，空态可直接前往对应页面。
- **课表**：默认周视图，按学期周次展示课程网格，支持单双周、跨节次合并、节假日调休与课程调整（停课/改期/换教室）。
- **课表导入**：支持 Excel / CSV / JSON 文件，以及北航 BYXT、天津大学 EAMS 教务导入；只读取课表，不保存教务账号密码。
- **日程活动**：新建/编辑/删除，支持全天项、提前 5 分钟至 1 小时提醒、标签归类。
- **待办**：截止时间排序、每日重复、长按拖拽排序、勾选完成、优先级。
- **倒计日**：考试/生日/假期/纪念日/自定义五类，未来升序、已过降序。
- **桌面小组件**：下一项安排、今日概览、今日待办、最近倒计日四个 Android 组件，支持桌面勾选待办。
- **数据备份**：课程、日程、待办、倒计日与提醒设置可导出为 JSON，换机时导入恢复。
- **原生通知（Android）**：`@capacitor/local-notifications` 整体重建排期，设置页内置诊断面板（权限、渠道、已排定数量、最近错误、试听与定时测试），点击通知直达对应页面。
- **应用内更新（Android）**：启动时每天检查一次，也可在设置中手动检查；下载后校验 SHA-256，再交由系统安装界面确认覆盖安装，不静默安装。
- **网页环境降级**：浏览器打开时退回应用内横幅 + 铃声 + 振动提醒，功能完整可用。

## 快速开始

需要 Node.js（仅用于起静态服务器，不装任何依赖）：

```bash
node dev/serve-web.mjs      # → http://localhost:8124
```

首次启动会读取 `web/js/seed-data.json` 的空快照，不预置课程、日程、待办或倒计日；之后所有读写都走 `localStorage`，不需要联网、不需要后端。直接用 `file://` 打开 `web/index.html` 不行（ES Modules 与 `fetch` 都需要 http 源）。

## 数据存储

- 课程、调整、活动、标签、学期、节假日、提醒总开关 → `localStorage` 单键 `appData`（一个 JSON 文档），校验与级联规则在 `web/js/store.js` 内实现（删课程级联删其调整、删标签置空活动的 `tag_id`）。
- 待办、倒计日、分渠道提醒开关 → 各自的 `localStorage` 键。
- `web/js/api.js` 是本地存储门面，函数名与返回形状和历史云端接口一致，页面模块因此不需要感知存储层。
- 首启导入由 `web/js/config.js` 的 `CLOUD_IMPORT_BASE` 控制：留空 = 使用内置空快照；填自己的站点 `https://<域名>/functions/v1/app` = 首次启动从云端拉一次（`functions/` 是可自部署的配套后端）。

## 目录结构

```
web/                    前端全部资源
  js/store.js           本地存储层：校验、级联、排序、持久化
  js/first-run.js       首次启动导入（云端 / 内置快照）
  js/api.js             本地门面，页面模块只依赖这一层
  js/native-notify.js   原生通知排期与诊断
  js/update.js          版本检查与 APK 下载安装
  js/pages/             五个页面模块 + 设置弹层
  js/adapters/          北航 / 天大教务适配器
  js/seed-data.json     内置空快照（正式版不预置数据）
functions/              可选的 Qoder Sites 云函数后端（adapter.mjs + handler.mjs + update.mjs）
update-site/            更新服务站点页面
updates/android/        线上更新清单
dev/serve-web.mjs       本地静态预览
test-*.mjs              纯 Node 用例，无需测试框架
PRD.md                  产品需求文档与各版本实施记录
```

Android 壳工程（`android-app/`）与 APK 产物不在本仓库中。自行打包：`npx cap add android`，`webDir` 指向 `www`，把 `web/` 拷进去，`capacitor.config.json` 里**不要**配 `server.url`（配了就又变回远程站点），并保留 `plugins.LocalNotifications` 与 `SCHEDULE_EXACT_ALARM`、`POST_NOTIFICATIONS`、`VIBRATE` 权限。

## 关于内置数据

- 正式版首次启动为空白数据，不预置任何课程、日程、待办、倒计日、标签或节假日。
- 仓库不包含个人课程快照或演示数据；需要数据时在 App 内添加、导入课表或导入备份。
- 想从自己的后端初始化：配置 `CLOUD_IMPORT_BASE` 后首次启动拉取。

在线站点现作为 Android 客户端的更新服务页：<https://gjq-schedule-2026-8ahpb1ikp5c.qoder.zone>
